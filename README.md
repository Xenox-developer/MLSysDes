# Predictive Maintenance

Краткое описание
---------------------
Проект: Predictive Maintenance.  
  Цель — реализовать pipeline для предиктивного обслуживания: очистка данных, обучение модели (LSTM), индикация аномалий.

Структура репозитория
---------------------
  __/data/__ - raw и processed данные  
  __/docs/__ - дизайн-документы и спецификации  
  __/src/__ - исходный код проекта  
  __/notebooks/__ - jupyter-ноутбуки с исследованием  
  __/models/__ - сгенерированные модели
